# my portfolio

This is my INFR3120 Assignment 1 website. It has four pages: home, about, projects, and contact.

## files

- `index.html` — home page
- `about.html` — about me, photo, and video
- `projects.html` — four project descriptions
- `contact.html` — contact form
- `style.css` — shared styles
- `mobile.css`, `tablet.css`, `desktop.css` — styles for different screen sizes

## layout

I used fluid widths and media queries. I did not use Flexbox or CSS Grid.

- Mobile: up to 600px. The page is 94% wide and the photo and video fit inside it.
- Tablet: 601–900px. The page is 92% wide.
- Desktop: 901px and wider. The page is 88% wide.

The photo and video fill the page width and keep their shape as they resize.

## colors and gradients

I chose the colors from my Adobe Color theme: `#EF41F2`, `#0B1926`, `#3E5951`, `#736F6C`, and `#595857`. Navy and green are in the gradients, magenta is used for the site name, and gray is used on the form fields.

There is a regular linear gradient in the header and an angled gradient in the footer. The assignment asks for both types.
